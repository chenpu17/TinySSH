# tmux 会话大屏（监控墙）轮（2026-11-03）

用户拍板原话：「开干！」——兑现上一条的方案：全部 tmux 会话以网格呈现（2×2/3×3/4×4），像监控多路摄像头，小窗可放大。

## 一、定案（含关键架构判断）

- **大屏 ≠ 更多格子**：面板格子=每格一条活 PTY（attach 客户端、可交互、进愿望清单持久），撑 2~4 格；大屏=**capture-pane 快照墙**（只读、零客户端零 PTY、每 2s 一次 exec 抓全部当前屏），撑 6~16+ 格。摄像头比喻的精髓是「看」不是「用」——要动手走「进格子」promote 回既有面板链路。
- 入口：tmux 快接菜单顶部加「会话大屏…」（菜单本来就只在 SSH+探测到 tmux 时渲染，零新增 chrome）。
- 网格：按会话数自适应（≤4→2×2、≤9→3×3、>9→4×4），头部可手动切 2/3/4。
- 交互：单击小窗=放大（solo），Esc 逐级退（放大→关屏），✕ 关屏；「进格子」= 复用 openTmuxPane（attach/改名跟随/愿望清单全复用）+ 收屏让位。
- 临时性：大屏不入 vault、绑定打开它的标签（换标签即关），关掉即无痕。

## 二、实现面

**核心（core-session / session-api）**
- `tmux_wall_snapshot(sid, targets)`：一次 exec 抓全部目标当前屏。帧协议防碰撞（坑 80/81 同族教训：pane 内容是任意字节）：`@@WALL|<下标>|<字节数>` 帧头 + 恰好 n 字节 + `@@WALL|END`；快照先落 shell 变量（哨兵 x 保尾换行）再计字节数——解析按数取字节，绝不在内容里找标记（碰撞单测钉死）。
- `-e`（带色）优先、`case` 空串回落朴素捕获（POSIX，无 `||` 无重定向）；目标选择器 id 在手用 `$N`（改名不跟丢）、缺了退化 `=名`（≥3.1 精确）；单引号转义。
- 上限防御：目标截断 32、载荷帽 4MB；缺 END=整包作废（调用方保留上一帧）。
- 新类型 `TmuxWallTarget`/`TmuxWallCell`（session-api）；Tauri 命令 `tmux_wall_snapshot`。

**前端**
- `components/tmux-wall.tsx`：整幅主区覆盖层（MonitorView 同款位、z-46）；格子=只读快照小窗；轮询 effect 只跑一次（清单/闭包走 ref，3s 会话轮询换引用不打断节拍）；挂载即拍 + 2s 节拍 + `document.hidden` 跳拍 + 卸载即停。
- Esc 自捕获（capture 先于应用 Esc 链）：放大→退放大→关屏。
- 「进格子」→ openTmuxPane → toast/防呆全复用 → 收屏让位工作台。

## 三、渲染层的弯路（真机排障轮，最终推倒重来）

初版用**每格一个静态 xterm**（写快照、隐藏光标）——真机连续踩坑：
1. dimensions getter 在渲染器未就绪时**读取即抛**（可选链防不住 getter 内部抛），premature write 还会把 Viewport.syncScrollArea 带炸 → 引入就绪门（字格尺寸可读才开写）。
2. 上一轮埋点时给兜底轮加的包装守卫写反（`madeRef === term` 在未就绪时恒假）→ 就绪门永不开。修守卫后：**恒定内容格（静态快照）恒空**——首写落在字体重测量窗口被吞，变化格因每拍重写自愈 → 加每 5 拍保活重画。
3. 仍空。逐层取证（walllog 生命周期日志 / DOM 文本 vs buffer API / A/B 写序列）：`term.reset()` 与 `\x1b[2J` 清屏在这版 xterm 上会让个别格写处理器坏死（写完缓冲恒空、纯写正常渲染）→ 改 `\x1b[H…\x1b[0J` 亦未根治 → 加单格坏死自愈（推过非空帧而缓冲仍空 → 就地重建，双确认防误杀，上限 8 次）。
4. 最终**整体替换渲染层**：快照是纯文本+SGR，根本不需要活终端——`ansiToHtml`（SGR 子集：16/256/RGB 色、粗斜下划删除、反显）直出 `<pre>` 内联 span。xterm 整类坑（就绪门/写处理器/维度/自愈）一次性消灭。

**教训：只读文本快照不该复用活终端组件——渲染层要按数据形态选，不按「看起来像终端」选。**

## 六、教训

1. **只读文本快照不该复用活终端组件**——渲染层按数据形态选，不按外观选。xterm 的价值在交互态机；丢掉交互就丢掉了用它的全部理由，留下的只有它的全部脆弱面。
2. **黑盒排障要尽早换成「把内部状态暴露出来」**：window 级日志数组（`__walllog`）一轮就看完整个生命周期剧本，比十轮盲测快。
3. **JS `replace` 的替换串永远用函数式**——本轮 `$'`（匹配后原文）特殊模式把插入文本截断+原文复制了一份，两轮修复才收敛。
4. **调试钩子的 DEV 门控会在真机上变成排障盲区**：`__t_pane_terms` 仅 DEV 注册，release 取证读空表——两行开销换全生命周期可观测，值得无条件注册。
5. 用户在开发机上实时使用应用会污染自动化走查（F5/点窗/遮挡）——哨兵（window 标记存活检查）+ 隔离实例 + 每轮收尾远端清点是最低卫生标准。
