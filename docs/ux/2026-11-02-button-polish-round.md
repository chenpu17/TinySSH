# 按钮美化轮：右键菜单 / 工具栏 / 全局按钮卫生（2026-11-02）

用户原话：「我们一些按钮比较丑，包括右键触发的，工具栏的，你看看也怎么优化下。」

## 一、诊断（截图 + 计算样式 + CDP 字体三证据）

病根只有一个：**全局 `button` 基础规则就是「主按钮」**（135° 渐变实底 + 600 粗体 + 内高光/投影 + 居中），
各族菜单/工具栏只覆盖了它的一部分属性，没覆盖到的全部漏出来：

| 现象 | 机理（实测） |
|---|---|
| 右键菜单像一摞描边按钮 | 菜单项是 `button.ghost`：每项继承 1px 描边 + 600 粗体 + 次级灰字 |
| 下拉菜单（工具 / tmux 快接 / 标签列表）项间一道道亮线 | `.tools-menu button` 没重置 `box-shadow`，继承主按钮内高光 + 投影 |
| 下拉菜单悬停没反馈 | 悬停底 `var(--panel2)` = 菜单底（计算值同为 rgb(31,34,50)） |
| 工具栏高低不齐、满屏框 | 图标钮 27px / 带图标文字钮 28px / 纯文字钮 30px 各算各的，全描边全粗体 |
| 左侧活动栏悬停变亮蓝实心方块 | `.rail-btn:hover`（0,2,0）输给通用 `button:not(:disabled):hover`（0,2,1）——悬停特异度陷阱，历史已修过 4 例同形 |
| 终端右键菜单首项一打开就套 2px 焦点环 | 菜单开即程序化聚焦首项（键盘可达）；焦点从 xterm 文本框转来时，浏览器启发式判 `:focus-visible` |
| 标签列表「已断开」被挤成两行 | 菜单最小宽 172px，状态字可折行 |
| **按钮字体与正文不是一套** | 表单控件不继承字体，UA 默认 `Arial`——CDP `getPlatformFontsForNode` 实测**全应用按钮与输入框的中文都落系统微软雅黑**，正文才是内置 MiSans VF（UX 五轮专门为治「土」观感引入的字体，唯独漏了按钮） |

## 二、改法（CSS 为主，TSX 少量）

1. **菜单项统一块**（styles.css 基础按钮规则之后）：`.ctx-menu`（五种右键菜单）/ `.tools-menu`（工具、tmux 快接、
   标签列表）/ `.split-menu` 会话表 / `.sftp-menu` 共用一套项样式——28px 行、无描边无阴影、正文色、正文字重 430
   （MiSans VF 是 150–700 真变量字体，450 就显粗，四档字重对照后取与 body 一致）、悬停中性浅底 `--quiet-hover`、
   键盘焦点浓一档 `--quiet-focus`（菜单内不画 2px 环，高亮即焦点指示，原生菜单同款）、危险项红字红底、禁用灰字
   不叠透明度、行内次级动作（「重连」「＋面板」）紧凑 accent 字钮。新 token 由 `--text` color-mix 派生，16 族 × 深浅
   自动成立。
2. **工具栏钮统一块**：会话工具栏 / 标签条尾部 / 任务面板头的直系钮统一 28px、500 字重；ghost 钮改**静默钮**
   （静息无框无底、悬停中性浅底）；开合/按下态（`.ts-open` / `aria-pressed` / `aria-expanded`）= accent 软底 +
   accent 字 + 细 accent 内描边；纯图标钮 28×28。接管（warn 实底）/ 接管并停止（危险描边）保留醒目配色。墨水屏
   阴影被专项块铲平 → 开合态补墨色实线描边。文件面板导航行同一语言（26px 静默方钮），筛选/排序 chip 选中态补
   accent 字与软底（此前只换框色，当前排序键认不出）。
3. **字体继承**：基础 `button` 与 `input, select` 加 `font-family: inherit`——全应用按钮/输入框换回内置 MiSans VF + Inter。
4. **次级钮字重**：`button.ghost` / `label.file-btn` / `button.ghost-danger` 600→500，与实心主钮（600）拉开层级
   （对话框「保存并连接 / 仅保存 / 取消」不再三颗一样粗）。
5. **扫描器揪出的同族漏网**（下节）：阴影泄漏补 `box-shadow:none`——`.ghost-danger` / `.sb-btn` / `.rail-btn` / `.hb-settings` /
   `.tab-split` `.tab-x` / `.mpause`（指标条与监控大屏两处）/ `.sftp-crumb` / `.mon-sw` / `.palette-item` / `.split-menu .sm-dir`，
   审查员补指 `.collab-badge` / `.hb-tag` / `.wr-row`（demo 默认态不渲染，扫描器扫不到）；悬停陷阱 4 族改 `button.` 前缀 + `:not(:disabled)`
   ——活动栏、监控采集开关 OFF 态（审查二轮只修了 ON 态）、分屏方向钮、⌘K 命令面板（鼠标悬停项是 accent 实底、
   键盘选中却是软底，两套高亮；改为高亮只跟选中项走）。
6. **TSX**：右键菜单项去掉 `ghost` 类；「关闭会话… / 删除主机…」标 `tm-danger`；工具菜单「关闭会话…」前加分隔线；
   右键菜单宽度随内容（200–340px）+ `clampIntoView` 挂载即测量回夹（文件菜单同用——它贴窗口右缘，旧估算 160 兜不住
   ~240px 宽的标题行）；焦点门控：菜单内按键或**键盘打开**（输入方式追踪：最后输入是键盘且无指针按下）才打
   `data-kbd` 显示焦点高亮，鼠标打开时首项持焦点但不亮（免首项常亮 + 悬停项双亮）；焦点不在项上时 ↑ 落末项
   （旧算式落倒数第二）；标签条「标签列表」补下拉 chevron、图标钮补 `icon-btn`；「新建连接」提示改随键位表渲染
   （审查轮二同类修复漏网：写死 Ctrl+T，mac 上也显示 Ctrl；tab-new 是 native 门动作，浏览器 demo 不广告——同命令面板钮）。

**刻意没做**：菜单项右侧键位提示（会把「功能」混进「美化」，且 demo 域多数快捷键是 native 门、提示会撒谎——
写过又撤了）；菜单图标（VS Code/macOS 惯例无图标，加了反而噪）；把基础 `button` 改成中性、主按钮改显式 `.primary`
（架构上更干净，但要给全应用每颗主按钮补类，改动面与本轮诉求不成比例——立案）。

## 三、全局按钮卫生扫描器

截图只能覆盖拍到的地方，于是写了扫描器（`.zcode/tmp/btn-scan.cjs`）：逐屏枚举可见且未被遮挡的 `<button>`，判
①阴影泄漏（静息透明底却带 box-shadow）②悬停陷阱（逐个真鼠标悬停，底色 = `--accent-fill-hover`）③字体未继承
（font-family 仍是 Arial）。覆盖 19 屏（主界面/文件/协作/设置 8 分区/Agent/Fleet/监控/新建主机/命令面板/传输抽屉/
广播/确认框）约 455 个按钮实例：改前 ①6 族 ②1 族 ③全部 → 改后**三项全零**（深浅两面）。审查员另指出 3 个 demo
默认态不渲染的 chip（主机栏标签筛选、欢迎页最近连接、标题栏协作徽章）同样泄漏，一并补齐。

扫描器固化为 **spec 64「按钮卫生」**：字体继承 / 阴影泄漏 / 悬停陷阱三项全局断言 + 工具栏 28px、工具菜单项规格
与悬停反馈、危险项红字与分隔线、右键菜单项去 ghost、焦点门控三态（鼠标开不亮 / ↓ 移亮 / 键盘开即亮）、右下角
右键回夹进视口——悬停特异度陷阱这是第 5–8 例，再出现会直接红。

## 四、审查

一路只读子代理审 diff + 前后截图（不跑浏览器，避免扰动正在跑的全套）：P2×1、P3×6。

- **P2 驳回（实证）**：「`ghost ts-open attn` 悬停时 warn 字被开合态的 accent 字顶掉」——审查员把 `button.ghost.attn`
  算成一个类，得 (0,5,1)；实为两个类 (0,6,1)，与开合+悬停同特异度、靠后胜出。合成元素真鼠标悬停实测：
  OPEN+ATTN 静息/悬停均为 warn 色。
- **P3 全部采纳**：接管钮字重与块注释不符（改注释）；3 个 chip 阴影泄漏（补）；`--quiet-press` 未用 + `data-hint`
  死规则（前者改作 `--quiet-focus` 用于键盘焦点、后者删）；键盘打开的菜单首项无焦点指示（加输入方式追踪）；
  9% 作唯一焦点指示在浅色/墨水屏偏淡（键盘焦点改 14%）；文件面板工具条仍是旧语言（改静默钮）。

## 教训

1. **表单控件不继承字体**：`button/input/select` 的 UA 样式自带 `font`，不写 `font-family: inherit` 就是 Arial →
   中文落系统回退字体。引入内置字体时必须连表单控件一起接上，验证要用 CDP `CSS.getPlatformFontsForNode` 看
   **实际渲染**字体——computed `font-family` 只是声明。
2. **「主按钮当基础规则」的设计会持续漏**：每加一个按钮族都得记得重置背景/描边/阴影/字重/悬停特异度，漏一项就丑。
   截图巡检只能覆盖拍到的地方——**扫描器 + 回归 spec** 才能兜住整类问题。
3. **`:focus-visible` 启发式会被文本框带偏**：程序化 `focus()` 时，若前一个焦点元素匹配 `:focus-visible`（文本输入
   框恒匹配，xterm 的隐藏 textarea 也算），新焦点也匹配——「键盘可达的自动聚焦」在鼠标路径上会冒出焦点环。
   要自己追踪输入方式（keydown / pointerdown）来门控。
4. **变量字体的数字字重不等于静态字体的名义字重**：MiSans VF 450 已近 Semibold，凭「450 比 400 稍实」的直觉调字重
   会翻车——字重决策要出多档对照图再定。
5. **新 spec 必须过变异再算数**：spec 64 首轮 14/14 全绿，变异却只红 6/9——过渡中途取色、残留指针的悬停冒充焦点、
   demo 数据恰好落在旧逻辑的安全区，三种「断言恒真」都只有注回缺陷才暴露。
