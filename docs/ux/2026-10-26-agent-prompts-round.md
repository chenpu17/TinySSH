# 2026-10-26 Agent 提示词/技能资产化轮 · UX 台账

定位：第三梯队第一项。内置 Agent 的提示词层从「lib.rs 字符串常量」升级为可定制资产：内置两段系统提示词搬进 `crates/agent-host/assets/*.md`（include_str! 静态内嵌、随二进制分发），用户可按组织/现场约定追加提示词段与维护技能库——**只追加、不替代**内置安全铁律（审批/不虚构/中文回复等契约行由测试钉死）。

界面落点：
- 设置 → Agent 新增「提示词与技能」卡（`agent-prompt-skills-card`，面板本地草稿工艺）：会话助手与 Fleet 编排者各一段附加提示词 textarea（maxLength 2700 字 ≈ 8KB，真侧 Rust clamp_utf8_head 同源截断保头）；blur 即存 + 面板卸载兜底（载入完成前不写，防清空竞态），各配「清空」按钮。
- 技能库（同卡）：名称（≤50 字）+ 操作手册正文（≤16000 字）行式编辑、添加/删除、显式「保存技能库」（草稿语义）；校验：≤32 条、名称非空、不重名，错误消息即时呈现。存储为 KV 单键 `agent.skills`（JSON 对象：名称→正文），列表计数（N/32）随行数。

行为与生效语义：
- 附加段追加在系统提示词尾部，带「用户附加约定（…与上方安全铁律冲突时以铁律为准）」标题——安全叙事不因用户定制稀释。附加段折进 agent 重建指纹：改设置 → **下一条消息即重建生效**，无需重开会话。
- 技能库只影响工具运行时：agent 新增第九个工具 `load_skill`（无参=列清单：名称+正文首行简介；带 name=全文；缺名如实报错），正文每次调用现读——**改技能无需重建 agent**。Fleet 编排者不挂技能库（任务自包含契约，机器侧流程归目标 agent 现场加载），系统提示词里的技能库引导行也只加在会话面。
- 技能库为空时工具如实报「技能库为空（可在 设置 → Agent → 提示词与技能 里添加）」——不静默装作没有这个工具。

边界与未竟：技能正文超 16K 字符由 UI maxLength 把关（工具侧不截断，用户自有内容自负）；附加段/技能库经 KV 读写，MCP/CLI 不暴露编辑入口（V1）；技能无启用/禁用开关（删除即下线）。

验证：agent-host 14/14（内置契约行钉死、无资产源=资产化前逐字节一致、追加/clamp/清单格式）；spec 58（13 断言：附加段×2 切分类往返回显、清空落 KV、技能 CRUD 往返、重名拒绝、空态退场/回归）；全套 815/815（50 specs）。
