# 2026-10-26 记录时间线可视化轮 · UX 台账

定位：第三梯队第二项（PRD FR-5「以任务/会话时间线呈现」的可视化补完）。记录审计从纯列表升级为**泳道图 + 明细**双层呈现：图回答「什么时候、哪台机器、动静多大、成败如何」，列表回答「具体做了什么、输出是什么」。

界面落点（设置 → 记录审计，明细列表上方内嵌）：
- **会话泳道 SVG**（`records-chart`）：每个会话一条泳道（标签=主机名映射，查不到显 sid 短 id）；x=时间在查询窗内线性映射（窗口下限 1 分钟——单条/同刻记录不至于挤成一个点，单点落窗中央）；刻度点颜色=终态（完成绿/出错红/已拒绝橙/超时黄/已取消灰/危险拦截深红），实心=Agent、空心=人类，半径=耗时对数映射（无耗时取基径）。
- **统计头**（`records-chart-caption`）：「N 条 · X 完成 · Y 已拒绝 …」只列在场终态——打开即有一眼总量与失败密度。
- **图例**（`records-chart-legend`）：在场终态色点 + 形状语义（实心=Agent/空心=人类/点大小=耗时）+「点击刻度定位明细」。
- **点击刻度 → 定位明细行**：scrollIntoView 居中 + 行描边闪烁约 1.7s 自动退场（刻度同步闪，双向对齐）。

诚实性设计：数据模型无「任务 id」（records 只有 seq/ts/kind/session/agent/summary/status），**不造假分组**——「任务视角」由时间邻近 + 会话泳道承担，泳道图直接吃当前筛选的 rows，零独立数据路径、筛选变化图行天然同步。SVG fill 属性不支持 `var()`，空心点 fill="none" 靠描边显形。

验证：spec 59（11 断言：200 刻度=200 行、统计头、单泳道、双形状并存、图例、点击闪烁出现与退场、筛选后图行同步 1=1、统计头更新）；spec 31 既有断言不受扰。
