## 3. P5 协议决定

**批准增补，按交付文档 §4 执行。** 从预热到 E 同步采集 `vm_stat`、只读压力状态、swap/压缩/页回收计数及时间戳；预先登记频率和失效判据。归属或压力条件失效则整轮不可判，保留原始数据并受控重测；禁止事后挑选安静 B/E 窗口，禁止主动 purge/制造压力。应用引发的压力须调查，不能当作外部环境直接豁免。≤20%、末段趋势、正确性及新旧相同缓存容量要求不变。

现有 v3 曲线的同步下降只能提示压力/回收，缺少同期系统观测不能确诊“外压 purge”。结合本次采样器探针，撤回“归属机制已经有效验证/采样器通过”；P5 保持不可判，必须先修仪表、绑定脚本版本、再整轮试点。

## 4. 受控复测授权

**批准专用测试机或独立测试登录会话**执行 P2/P4/P7、P6 同进程循环与 P5 试点，权限覆盖必要的任务自有应用实例、测试 DB/sshd 与测试产物。执行前记录环境、目标 PID/启动身份/窗口/目标控件，验证拒绝路径及任务资源清理。

只用 ev2 PID 定向投递和逐事件守卫；不得回退全局 HID 注入。PID 定向降低误投风险，但不等于不存在身份复用、检查后状态变化或控件落点问题。三项拒绝自测不替代完整输入链验证。

本授权不包含当前用户正在工作的桌面，不安排或推定本机“15 分钟空闲窗口”，不关闭用户浏览器。若团队无法提供受控环境，保留环境阻塞并按上述期限处理；无需为已批准的独立环境再请求一次产品确认。本次没有执行任何原生键鼠注入或压力采样。
