# UX-R1 · R01 三页面可交互原型

> 2026-10-06 [G0 签署勘误](../g0-signoff.md)：原型作为 G1 设计输入接收；OutcomeUnknown 当前“重试/丢弃”交互未获批准，须在 G3 前改为“重新核实/查看记录”，不以模拟重试到 done 作为契约预期。下方旧走查记录保留为历史。
纯前端单页原型（无框架、无 CDN 依赖），浏览器直接打开即可：

```
open index.html
```

- 顶部右侧「状态场景」菜单切换全部演示状态；「太阳/月亮」按钮一键切换明暗主题（终端配色独立，浅色下终端保持深色）。
- 所有数据均为模拟数据，不连接任何服务器。

## 场景清单

| 场景 | 说明 |
|---|---|
| 欢迎页 · 新装机 | 无主机空态 + 添加连接 / 导入 SSH 配置 / 打开本地终端 |
| 欢迎页 · 已有主机 | 最近连接 5 张卡片 |
| 终端工作区 | 8 个标签（同名主机带序号、长中文名、已断开态）、工具栏、ANSI 着色终端 |
| 终端 + 文件并排 | 384px 文件面板 + 传输抽屉（进行中 / 冲突待决 / 已完成） |
| 连接失败 | 错误条：对象 + 原因 + 下一步（重试 / 编辑主机 / 技术详情） |
| 已断开重连 | 断线横幅：重连 1/5、立即重连 / 停止重试 |
| 指纹变更确认 | 新旧 SHA256 对比弹窗（拒绝 / 信任新指纹并继续） |
| 同名冲突 | 跳过 / 保留两份 / 替换（替换为危险按钮） |
| 提交结果未知 | 任务卡「结果未知」态：重试（先核对远端）/ 丢弃 |
| Agent 首次委托与审批 | 批准 / 拒绝模态 → 首次委托确认 → 会话内模拟执行与回传 |
| 窄窗文件全视图 | 空间不足时文件切换为完整视图 +「返回终端」（收起文件面板） |

URL 参数（可选）：`index.html#s=<场景键>&theme=light|dark`；亦可用 `#s=terminal` 等直接进入。场景键见 app.js `SCENARIOS`。

## S01–S11 关键状态覆盖矩阵

| 状态 | 原型入口（可点击路径） |
|---|---|
| S01 欢迎 / 新装 | 场景「欢迎 · 新装」；或删除全部会话后回到欢迎页。添加连接 / 导入 / 本地终端按钮均可走 |
| S02 主机库管理 | 主机栏：搜索 / 标签筛选 / 收藏 / 右键菜单（新建会话 / 编辑 / 删除确认，删除不断开活动会话） |
| S03 连接进行中 | 连接任意主机：侧栏行「正在连接」+ 取消按钮 + 标签连接中态；密码主机额外走两轮 keyboard-interactive 挑战 |
| S04 认证与凭据 | 添加连接表单选「密码」（密码框）/「粘贴 / 导入私钥」（密钥内容 + 可选口令）；设置 → 凭据（列表、未绑定标记、删除引用检查） |
| S05 终端工作区 | 场景「终端工作区」；标签切换 / 分屏（窗格焦点联动工具栏与文件面板目标）/ 终端内搜索（真实匹配计数与高亮）/ 模拟键入命令（whoami、ls、echo、clear 等） |
| S06 连接异常 | 场景「连接失败」（错误条：对象 / 原因 / 下一步）与「断线重连」（横幅 + 立即重连 → 新连接边界提示） |
| S07 文件与传输 | 场景「终端 + 文件并排」：面包屑导航 / 多选下载 / 上传 / 传输抽屉；进行中任务自动走 running → 提交中 → 已完成 |
| S08 窗口与布局 | 拖动侧栏 200–300px / 收起展开；960 宽度文件自动完整视图，「返回终端」收起面板回到终端 |
| S09 转发 | 状态条「转发」→ 转发列表 → 新建转发（类型 / 监听 / 目标表单）→ 连接中 → Listening → 停止 |
| S10 协作（Agent） | 场景「Agent 首次委托与审批」：请求模态 → 批准 / 拒绝 → 首次委托确认 → 会话内执行与输出回传 |
| S11 设置 | 设置模态：外观（即时切换）/ 终端（字号、回滚行数，即时 toast 持久化模拟）/ 凭据（引用检查删除）；其余分类按任务计划占位 |

注：全部为模拟分支，不连接真实后端；矩阵中每条路径在原型中均可实际点击走通。

## 主要交互

主机单击选中、双击/悬停按钮连接（模拟 1.3s 延迟）→ 标签切换 → 文件面板开合（⌘⇧E 视觉）→ 抽屉展开/收起 → 主题切换 → 侧栏宽度拖动（200–300px）与收起（⌘B 视觉）→ 主机右键菜单（连接 / 编辑 / 删除确认）→ 标签关闭确认（有活动任务时）。

## 实现口径备注

- 传输抽屉高度 = `min(240, 45% × 工作区高度)`（§4.2「240 高、最大 45%」），随窗口 resize 重算；任务数增多时在抽屉内滚动，不改变抽屉高度。因此部分窗口尺寸下实测高度会低于 240，为规格内的 45% 上限生效，非缺陷。
- v1.2 修订（2026-10-06 复验后）：`.btn-danger` 文字改 `accent-onFill`；新增 `border.input` token 用于输入框边界；`.mode-full` 同时隐藏 `term-area`。
