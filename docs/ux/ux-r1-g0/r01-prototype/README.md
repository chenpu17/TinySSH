# UX-R1 · R01 三页面可交互原型

纯前端单页原型（无框架、无 CDN 依赖），浏览器直接打开即可：

```
open index.html
```

- 顶部右侧「状态场景」菜单切换全部演示状态；「太阳/月亮」按钮一键切换明暗主题（终端配色独立，浅色下终端保持深色）。
- 所有数据均为模拟数据，不连接任何服务器。

## 场景清单

| 场景 | 说明 |
|---|---|
| 欢迎页 · 新装机 | 无主机空态 + 添加连接 / 导入 SSH 配置 / 打开本地终端 |
| 欢迎页 · 已有主机 | 最近连接 5 张卡片 |
| 终端工作区 | 8 个标签（同名主机带序号、长中文名、已断开态）、工具栏、ANSI 着色终端 |
| 终端 + 文件并排 | 384px 文件面板 + 传输抽屉（进行中 / 冲突待决 / 已完成） |
| 连接失败 | 错误条：对象 + 原因 + 下一步（重试 / 编辑主机 / 技术详情） |
| 已断开重连 | 断线横幅：重连 1/5、立即重连 / 停止重试 |
| 指纹变更确认 | 新旧 SHA256 对比弹窗（拒绝 / 信任新指纹并继续） |
| 同名冲突 | 跳过 / 保留两份 / 替换（替换为危险按钮） |
| 窄窗文件全视图 | 空间不足时文件切换为完整视图 +「返回终端」 |

URL 参数（可选）：`index.html#s=<场景键>&theme=light|dark`；亦可用 `#s=terminal` 等直接进入。场景键见 app.js `SCENARIOS`。

## 主要交互

主机单击选中、双击/悬停按钮连接（模拟 1.3s 延迟）→ 标签切换 → 文件面板开合（⌘⇧E 视觉）→ 抽屉展开/收起 → 主题切换 → 侧栏宽度拖动（200–300px）与收起（⌘B 视觉）→ 主机右键菜单（连接 / 编辑 / 删除确认）→ 标签关闭确认（有活动任务时）。

## 实现口径备注

- 传输抽屉高度 = `min(240, 45% × 工作区高度)`（§4.2「240 高、最大 45%」），随窗口 resize 重算；任务数增多时在抽屉内滚动，不改变抽屉高度。因此部分窗口尺寸下实测高度会低于 240，为规格内的 45% 上限生效，非缺陷。
- v1.2 修订（2026-10-06 复验后）：`.btn-danger` 文字改 `accent-onFill`；新增 `border.input` token 用于输入框边界；`.mode-full` 同时隐藏 `term-area`。

## 自检记录（headless Chrome 实测）

- 1280×800：三主视图 + 全部异常态截图无裁切、按钮可达。
- 960×600：文件面板按 §4.2 切换为完整视图（DOM 验证 `mode-full`）；1280 下为 `mode-side`。
- 双主题：未发现白底白字 / 黑底黑字；终端在浅色主题下保持深色底。
