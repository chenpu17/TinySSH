## 4. 行为变更总清单（升级用户可见差异，随发布说明）

1. 三栏固定 → 默认主机栏+终端，文件/协作按需（§4）。
2. 侧栏会话卡 → 顶部标签；命令框移除，终端直接输入（§5/§6.3）。
3. 人类新建会话默认 Human-owned（C2，破坏性语义收紧，旧测试/Agent 工作流受影响）。
4. 主动断开入口统一「关闭会话」；意外断线保留画面+重连（§6.4）。
5. 连接：全局禁用 → 并行 attempt + 同主机合并（Q8/§6.2）。
6. 主机行点击模型：现状「单击=切最近会话或直接建连」（App.tsx:1716-1720）→「单击选中、双击连接；均断开时聚焦断开标签供重连；新建会话显式另建」（§6.1，R20/R21）。
7. 传输终态对账：前端 800ms 审计轮询 → 核心任务注册表事件（C5）。
8. 传输写入：直接截断覆盖 → 冲突门 + 提交/OutcomeUnknown（C6，含 MCP `collision` 缺省 fail——Agent 传输行为变更）。
9. 建连：不再无条件注入/等待 shell 集成（C3/P3）；新主机默认关闭，升级主机保留设置但运行时检测。
10. mode=Shell 能力不可用从静默 Fresh → 执行前稳定拒绝（C3，D09/§10.2 登记的破坏性变更）。
11. 导入：静默丢弃未支持指令 → 分级诊断 + 默认不可直连（C7）；无 User 条目不再静默 root（DF7.5）。
12. 偏好：`ui.theme/ui.font_size` → `ui.v2.*` 一次性映射（C8；旧键保留供回退读取）。
13. 协作 UI：常驻右栏 → 按需入口 + 全局审批待办；MCP 端点：装配即启动 → 生命周期可停用（C9；新装默认关闭、升级保留开启，§10.1.6）。
14. 删除凭据：无检查 → 引用检查（DF8.4）。
