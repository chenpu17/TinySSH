# 分屏组命名轮（2026-10-30）

用户提出：拖动标签成左右分屏后，两个连接能否合并为一个 **group**——自动生成名字、
用户可重命名；「其他终端软件好像也是这样」。拍板按提案落地，纯前端，Rust 零改动。

## 设计定案：组 = 分屏对本身的命名层

现有分屏就是全局唯一一对（`SplitPanes = { main, second, dir }`），所以「组」不需要
新数据结构——它是分屏对的命名视图：

- **自动名**：两成员显示名相连（`A + B`），显示名 = 标签改名名 ?? 主机名。
  渲染期从成员实时推导（`splitGroupLabel`），成员替换/交换自动名跟随，不动任何
  分屏形成代码。
- **自定义名**：`splitGroupName` 非空即钉住——成员替换不跟随；清空提交 = 退回自动。
- **改名入口**：双击分割条中央胶囊；标签右键菜单「重命名分组…」（预填当前名）。
  键盘契约与标签重命名同款（Enter/blur 提交、Esc 取消、IME 组合期守卫），
  另加 **onFocus 全选**——往 `A + B` 后面追加几乎没人要，替换才是主路径。
- **生命周期**：散伙即弃名，重分屏重新自动生成。散伙点共五处：退出分屏、
  detach（欢迎页）、成员关闭 ×2（disconnectSid 主/副格分支）、termsRef 对账
  （外部关闭，Agent 经 MCP close_session 等）。重连不掉（sid 稳定，分屏本就跨重连）。
- **不入 vault**：会话本不跨重启，组同寿命（与 tabNames 同款口径）。
- **显示位**：分割条中央胶囊（主）；「退出分屏」钮 tooltip 带组名；右键菜单入口。
- 明确不做：XShell/SecureCRT 式层次标签组（组容器装 N 标签、不必在屏）——要标签条
  层次化，另一量级。iTerm 式广播组已有相邻物（34-broadcast 手动勾选集），将来可加
  「把分屏组设为广播集」一键，本轮不动。

## 交互契约：点胶囊=改名，抓条身=拖比例/双击复位

胶囊叠在分割条正中央，事件自持（pointerdown/dblclick stopPropagation）：抓胶囊
改名、抓条身其余段拖比例、双击条身复位对半。代价：正中心 10px 不再是拖拽握点
（条身两侧任意位置都是），可接受。

## 两坑

- **坑 86：`::after` 树序绘制盖掉兄弟胶囊**——`.pane-div::after`（1px 中线）是
  生成内容的**最后一个子盒**，与胶囊同为 z-index:auto 定位元素时按树序后绘者在
  上：中线正好压在胶囊上方，胶囊中心的 elementFromPoint 打回分割条本身，双击
  全落条身（改名开不了、frac 反被复位）。修 = 胶囊 `z-index: 2`。诊断法：
  `document.elementsFromPoint` 全栈（同一个元素出现两次 = 既有自身盒又有伪盒参与）
  + 胶囊面 5×3 网格命中图（grid 探针在 .zcode/tmp/chip-dbg2.cjs）。
- **spec 30 取点迁移**：拖拽/双击复位原从 `divCenter`（条身正中）取点——恰是胶囊
  位。helper 换 `divPoint(f)`（f=沿长轴位置分数），拖拽抓 f=0.2、复位双击 f=0.8。

## 边界如实

- 分屏退化态（窄窗 splitDegraded）胶囊随分割条一起消失——退化时单窗格，组名无处
  安放，恢复宽窗即回。
- 胶囊 hover 有边框/文字提亮 affordance；全名在 title（长名截断省略）。
- 改名框 blur 提交沿标签重命名先例（Escape 卸载不触发 blur 提交，同款安全）。
