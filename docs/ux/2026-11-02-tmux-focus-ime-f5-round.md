# tmux 面板焦点框 + Ctrl+B $ 输入法标点 + F5 重载轮（2026-11-02）

用户原话：「F5的问题你也安排上。另外多tmux的窗口管理，有两个小问题，一个是第一个出现的tmux窗口，后续选择的外框好像没有，其他tmux窗口选中的时候有外框，另外外框的颜色能否明显点，有点看不出来。 ctrl+B $ 修改tmux会话名称好像出不来。但是分屏没问题。」

## 一、F5 重载重复开本机标签（审查轮二走查立案项）

**病根**：启动自动开本地终端的 effect 只靠组件内 `autoLocalRef` 防重——F5/Ctrl+R 重载 WebView 时核心进程与会话都还在，前端却从头挂载，ref 归零，每重载一次多开一个本机标签。

**修**：以核心会话表为准（决策时现取 `list_sessions`，不吃 state 装载时序）：已有任何未关闭会话 = 重载续用，不开；取不到按冷启动处理。

**修完暴露的第二层**：重载后停在欢迎页——此前多开的那个本机标签反而让人「看到了终端」。F5 应是无损的：活动 sid 记 `sessionStorage`（随 WebView 会话存活、应用重启即清——冷启动不会误吃上次运行的值），重载续用时回到重载前的标签。细节：仍在册才回；装载期间用户已点了别的不抢；欢迎页上重载如实留在欢迎页；首拍 `sid=null` 是挂载初值不是「离开标签」，跳过不抹。

Tauri-only（demo 域豁免同原自动开），真机守门。

## 二、焦点格指示

**诊断**：「第一个出现的 tmux 窗口」= 主视图（先 attach 的那个）。网格里主视图**根本没有焦点指示**（只有分屏模式的 `.pane-focused` 有）；格子的是 `outline: 1px solid var(--accent-glow)`——accent 35% 半透明，确实看不出。

**修**：主视图与格子同一套——
- `::after` 叠层 2px accent 实线框（实线 border，墨水屏铲阴影不受影响；穿透指针；z 7 压过主视图标题栏 `.pane-tag` 的 z 5；框只占边缘 2px，终端正文在 padding 内不被盖）；
- 标题栏 accent 字 + 不透明浅底 `color-mix(accent 14%, --panel)`（主视图标题栏下面是终端底色，半透明会透出来）；
- 判据统一 `:focus-within`，删掉格子各自挂的 focusin/focusout 监听。

**顺带**：分屏模式焦点窗格原是 1px `--accent-glow` 内描边**阴影**——同样看不清，且墨水屏铲阴影后分屏焦点窗格完全无指示。改为同一语言的 2px accent 实线。

## 三、Ctrl+B $ 改名框出不来

**诊断**：本机唯一输入法是微软拼音（`Get-WinUserLanguageList`：zh-Hans-CN，TIP `{81D4E9C9…}`）。中文标点模式下 Shift+4 提交「￥」（U+FFE5），而 % 仍是 %——「分屏好使、改名出不来」正是这个指纹。tmux 前缀表里没有「￥」：不弹改名框、什么也不发生（按 tmux 键表逻辑：前缀表不中 → 回落根表仍不中、且不是首个尝试的表 → 丢弃）。用户在格子里跟 claude code 说中文，常驻中文模式。同样静默失效的前缀命令：`$` 改会话名、`,` 改窗口名、`"` 上下分、`:` 命令行、`[` 复制模式、`!` `'` `(` `)` `;` `?` `~` `{` `}`。

**修**：前缀后一键的输入法标点还原——
- 窗口捕获层把 C-b 直发给 **tmux 目标**时武装：格子恒是 tmux 客户端；主视图须 `tmux_attached`（手动敲的 tmux 无从得知，宁缺不错——非 tmux 下 C-b 是 readline 光标左移，紧随其后打的中文标点是真文本）；
- 该目标下一份 `onData` 一次性消费：输入法标点还原成物理键位的 ASCII（全角区 U+FF01–FF5E 固定偏移，加 ￥“”‘’、。《》〈〉【】「」〔〕……——· 与全角空格），其余原样；5s 过期；Ctrl/Alt 直发即解除；
- 纯函数 `ui/src/terminal/ime-punct.mjs`（spec 直测真值表）。

**为什么挂 onData 不挂 keydown**：输入法上屏路径不唯一（组合事件 / insertText / keyCode 229 后的 textarea 差分），`onData` 是唯一共同出口。中文模式下的**字母**会进拼音组合窗（用户看得见候选框），不在本轮范围。

## 五、立案：改名后界面不跟随（真机观察，待拍板）

改名在 tmux 里已生效，但面板模型按**会话名**认格：
- 格子标题、主视图名牌仍是旧名；
- 快接菜单重探后列出新名且「＋面板」可用——同一会话可再开一格（防呆按名字失效）；
- 主视图会话被改名后，探针校正把 `tmux_attached` 当残留清掉 → 快接钮回到「tmux」，主视图的前缀标点还原随之停用；
- 掉线重建按旧名 attach → 判「会话不存在」摘格。

**建议修法**：按 tmux 不可变的 `session_id`（`$N`）认会话——探针加 `#{session_id}`，开格/attach 时记 id，探针对账按 id 改名（核心 wishlist/panes/tmux_attached + 前端布局树叶子改名）；改名提交（前缀 `$` 之后的回车）后补一发探针，让标题即时跟上。

## 教训

1. **「外框看不出来」先查有没有**：主视图在网格里压根没有焦点指示，只调颜色治不了「第一个窗口没框」。
2. **输入法不只吞 Ctrl+字母**：中文标点模式把标点键换成别的字符，所有「前缀 + 标点」的终端快捷键（tmux/screen）都会静默失效。「% 好使、$ 不好使」就是指纹。
3. **取证脚本先跑对照组**：「前缀后的 ￥ 是丢弃还是转给程序」两种量法（远端 grep 多字节 / `cat -v`）的对照组（不带前缀的 ￥）本身就读出 0——量法无效，结论不能用。最终以可靠观测（不弹改名框、会话名不变）+ tmux 键表逻辑定案，进度汇报里一度说的「￥ 进了输入框」已更正。
4. **被中断的走查会留残局**：上一次中断的走查已把 tspwt-a/b/m 改名成 r1..r3，下一次的改名撞重名全红。走查前置清理要按前缀全杀，不能只杀本脚本要建的那几个。
