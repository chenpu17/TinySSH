## 独立审核发现（rev-r44 首轮不可签 → 已处置）

审核员以**真二进制**复现两条高阻断（非读码推断）：

- **F1**：`open()` 先 `PRAGMA journal_mode=WAL` 再进护栏。`journal_mode=WAL` 会改写库文件头
  并把库永久切到 WAL——审核员对一个非 WAL 的未来版本库实测 sha256 变化、`journal_mode`
  由 `delete` 翻成 `wal`。**主张被证伪**：注释与 README 的「任何写操作之前」「一个字节都不写」
  当时不成立。**处置**：只读 `ensure_schema_supported()` 前置到设 WAL 之前；补非 WAL 库
  逐字节断言用例（RED-M7 实证判别力）。
- **F2**：`restore_from` 只查 `hosts` 表。审核员以真二进制复现：指向「恰好有 `hosts` 表的
  垃圾文件」→ 真库 **11 张表 → 只剩 `hosts`**、应用再也打不开、无任何回退。**处置**：校验
  升为 **V1 核心表全套**；**先在临时副本上试迁移到链尾再动目标库**（原为「先覆盖、后验证」）；
  覆盖前自动留 `<db>.pre-restore.bak` 安全副本（`VACUUM INTO`）；CLI 打印副本路径
  （RED-M8 实证）。
- **F3（中，证据缺陷）**：`cli-smoke.txt` 是坏 harness——整条命令行当单个 argv 传（zsh 不按
  空格分词），7 条命令实际全报 `unrecognized subcommand`，而 README 宣称「全在且可用」。
  **主张为真、引用证据相反**。**处置**：命令与参数分开传、逐族真调用重跑（已重生成）。
- **F4（中）**：「MCP 端点可用」是据 `collab_enabled()` 的推断非实跑。**处置**：README 措辞
  降级并标注为推断。
- **F5/F6（低）**：锁粒度=每个 `Vault` 对象（同进程两个也互斥）；护栏拒绝后残留空 `.lock`。
  **处置**：均**有意为之**并在 `VaultLock` 文档注释写明理由（锁文件**不可** unlink——A 持锁时
  B unlink → C 建同名新文件拿到独立锁 → 互斥破坏）。审核员另确认 `drop(m2)` 是**正当修正**、
  非掩盖缺陷（对照 HEAD 原文核过）。
- **F7/F8（低）**：`restore_from(from==db_path)` 未测；`backup_to` 对不存在的库会先建空库。
  **处置**：各自加显式拒绝 + 用例（RED-M9/M10 实证）。
- **N-1（低，二轮发现 / 三轮补刀）**：`restore_from` 以**只读**打开**来源**校验，而只读打开
  WAL 库仍会写 wal-index（`-shm`/`-wal` 侧车），会在来源旁留文件、只读介质上失败。
  **二轮处置（库层）**：`restore_from` 改为把来源（连同侧车）拷到私有临时文件
  `<db>.restore.src` 再读，绝不在来源旁写；新增 `r44_restore_does_not_touch_source_sidecars`
  （RED-M11 实证）。**三轮复核发现只修了一半**：CLI 在 `restore_from` **之前**仍调
  `read_schema_version(&from)`（`crates/cli/src/main.rs`），同样只读打开原始来源 → 真二进制
  `vault restore` 仍会漏侧车、只读介质上仍失败。**三轮处置（CLI 层）**：`restore_from` 改为
  返回在副本上读出的来源版本，CLI 删掉预探测、直接用返回值（RED-M12 实证；`cli-smoke.txt`
  D 节为真二进制证据）。两处均已 Edit 反向还原。

## 附带发现（非变异，属实现缺陷）

RED-M4 的写锁在**既有测试** `r32_tests::r32_restart_recovery_marks_interrupted` 上暴露了
一处真实冲突：该用例模拟「进程重启」，但未 drop 上一个 manager（`m2` 存活到函数结束），
在新写锁下会挡住后续 `open`。**这不是锁的错误**——「同一 vault 两个活着的 manager」正是
§10.2 写锁要禁止的状态。修法是让用例先 `drop(m2)`（恢复其「顺序重启」本意），已在
`crates/core-session/src/r32_tests.rs` 就地修正并注明。修后该用例绿。
