## 三、入口与退出码

```bash
npm test --prefix ui          # 或 node ui/test/run.cjs
node ui/test/run.cjs 05 09    # 只跑名称含 05 / 09 的 spec
```

| 退出码 | 含义 |
|---|---|
| 0 | 全部通过 |
| 1 | 有断言失败 |
| 2 | 环境问题（dev server 未起 / 找不到浏览器） |

环境变量：`TINYSSH_UI_BASE`（基址，默认 `http://localhost:5183`）、
`TINYSSH_UI_CHROME`（显式指定浏览器可执行文件）。
