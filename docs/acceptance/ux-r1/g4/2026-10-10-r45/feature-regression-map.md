# R45 功能 → 回归映射表

范围：R45 验收项「**所有既有功能有映射与回归结果**」与「**无旧常驻命令框/三栏断言**」
（`docs/ux/ssh-client-ux-refactor-delivery.md:102`）。

口径说明（证据不得超出主张）：

- **「已覆盖」**= 该功能在 `ui/test/specs/` 里有断言，且断言在本轮**真实跑过**并通过
  （见同目录 `ui-test-run.txt`，**236 项断言**全绿）。断言走 `data-testid` 与语义类名，
  **不含**任何旧三栏坐标（220/780/280）。
- **「部分覆盖」**= 入口/结构有断言，但某条分支（如错误态、门控）未覆盖，已在备注里写明缺什么。
- **「未覆盖」**= 本轮没有自动化断言；要么登记为原生域（需真窗口），要么登记为待补。
  这类条目**不主张**已验证。

## 三、独立审核驱动补强的断言

两位独立审核者（rev-r45 / vis-r45）在**审核前**的套件里找出 3 处「过弱/空转」断言，
已逐条补强（断言总数 228 → **236**）：

| 位置 | 审核前 | 补强后 |
|---|---|---|
| `06-log` 主体筛选 | 只断言 `nAgent <= nAll`；把筛选改成空操作仍 14/14 全过（rev-r45 M3） | 逐行核对 `data-actor === "agent"` + `nAgent < nAll` |
| `06-log` 类型筛选 | 只断言下拉项**存在**，从未选中验证 | 选中 `exec` 后逐行核对 `data-action === "exec"` + 行数减少 |
| `02-session` / `11-tabs` 终端 | `!!querySelector(".xterm")`——多会话下 **0×0 幽灵元素**即可满足（vis-r45 实测） | 按 `getBoundingClientRect()` 筛**非零尺寸**的终端 |
| `15-goal` H1 瞬态 | 稳态读值（+1200ms），抓不到「一帧闪现」（rev-r45 低） | 高频采样切换后每一帧 + 「输入框一直在」防空转 |
| `08-collab` 徽标 | 三段析取，无法确认恰好变 1 | 断言**恰好**「1 待审批」 |
| `09-settings` 终端/关于分区 | `bodyText.length > 0`（近乎恒真） | 断言分区**实际内容**（「多行粘贴保护」/「TinySSH + 本地优先」） |
| `05-files` 清除选择 | 点 ✕ 包在 `if` 里，找不到就静默跳过 | 断言 ✕ 存在 + 清除后选中条消失 |

## 四、旧散落脚本的处置

`ui/` 根目录原有 **20 个** `*.cjs` 走查脚本（T38–T44 时期），全部**写死个人浏览器路径**
且多数**断言旧三栏坐标**。R45 把其中仍然有效的**功能覆盖**迁进 `ui/test/specs/`
（映射见上表），随后删除这 20 个脚本；逐条处置与「未迁移项」见 `old-probes-retirement.txt`。

`docs/acceptance/ux-r1/g*/**/*.js`（90 个 `.js` + 7 个 `.cjs`，共 97 个）**保持原样**：它们是各轮**历史证据**
（被当轮 README 引用），不是可重复运行的入口；改写历史证据会伪造记录，故不动。
它们仍在仓库历史里，必要时可作参考。
