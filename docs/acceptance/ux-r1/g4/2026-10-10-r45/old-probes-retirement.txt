# R45 旧散落脚本退役清单（`ui/` 根目录 20 个 `*.cjs`）

## 为什么退役

这 20 个脚本是 T38–T44 各轮的**一次性走查脚本**，共同问题：

1. **写死个人浏览器绝对路径**：`/Users/chenpu/Library/Caches/ms-playwright/chromium_headless_shell-1243/...`
   —— 换机/换 Playwright 版本即全废，且把个人目录带进了仓库。
2. **多数断言旧三栏坐标**（220 / flex / 280 或「三栏实测宽度」），R12 后该布局**已不存在**，
   留着就是**过时断言**——正是 R45 验收项「无旧常驻命令框/三栏断言」要清的。
3. 部分是**截图脚本**（输出到 `/tmp` 或 `docs/acceptance/screenshots`），不是可重复的回归入口。
4. 少数依赖**临时改 `ui/src/demo.ts`** 才能跑（跑完须人工还原），本身不可重复运行。

处置：**有效的功能覆盖迁进 `ui/test/specs/`**（见 `feature-regression-map.md`），
其余**如实登记为未迁移**（不主张已验证），然后删除这 20 个文件。

## 未迁移项汇总（不主张已验证）

**过时/废弃**：三栏宽度类断言（布局已移除，**不应**迁移）。

**登记待补**（本轮无自动化断言）：
卡片几何中心点击不被拦截、截断名 title 提示、目标草稿切标签不丢、textarea 自动增高、
简报可读性、首载 skeleton、attach-hint 生命周期、placeholder/`.dim` 对比度、
幽灵点击像素实证、连接 loading ≤400ms、无效私钥粘贴拦截、主机卡 auth 徽章、
SFTP「上一级」/路径手输/不存在路径报错、转发 -R/-D 类型与 sid 归属与审计、
转发行 Degraded 展示、审批 `editable` 门控、goal 变迁进简报、连接 spinner。

这些是**已知缺口**，不是「已验证」。后续如需覆盖，应写成**无个人路径、无临时注入**的 spec。

## 删除方式与复核

用 `/usr/bin/git rm` 删除（避免 conda git 的 UTF-8-MAC 陷阱），`git status` 显示 20 条 `D`。
删除后 `ls ui/*.cjs` → 无匹配；`ui/` 根目录不再有脚本，回归入口统一为 `npm test --prefix ui`。
