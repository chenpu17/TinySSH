## 关键设计事实

- **选择域随目录走**：换目录（任何导航路径）清选择/光标/锚点——「路径/选择恢复」的恢复面=会话快照（切回会话时按快照恢复），不是跨目录保留选择。
- **历史栈存 canonical 路径**：返回/前进直接 loadDir 不再入栈；导航入栈仅在「成功且路径真变化」时发生，刷新/首载/恢复不产生历史噪声。
- **面包屑是视图、路径框是编辑态**：sftpPath 恒为权威；sftpEditPath 为全局视图偏好（筛选/隐藏/排序同），不随会话快照走。
- **demo 树补丁**：/var/log/nginx 加 `.rotate.state`、/root/deploy 加 `.env`（显示隐藏项判别面）；传输模拟（R32）使多选下载/动作菜单在 demo 域端到端可见。

## 执行插曲（如实）

0. **切会话竞态（作者自查，两面判别）**：恢复快照不升请求代际——B 已具快照（二次进入不走首载链 loadDir）时，A 的在途 loadDir 响应可在切回后覆盖恢复态（路径+条目整体被换）；连带缺陷=被作废响应的 finally 不清 loading → 面板骨架卡死。修=切会话统一 `sftpGenRef.current++` 作废 + `setSftpLoading(false)` 复位；r31-race-probe 6/6 且摘修复复跑两面判别红（见 e2e 节）。
1. **选择条布局移位抓双击**：选择条初版渲染在列表上方——单击选中后布局下移，双击的第二击落在选择条上（dbg 事件流：mousedown:row→click:row→mousedown:sftp-selbar→dblclick:sftp-selbar，只有一次 click 到达行）。修=选择条移到列表下方（上方插入使列表位移是根因）。
