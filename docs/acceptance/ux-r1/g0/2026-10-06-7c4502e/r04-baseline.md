## 2. 统计方法（全部采样统一）

- **可操作口径（P1，Q-04 后）**：`operable = per-run 信标 <run_id>|s2-list-ready 到达时刻 − spawn 时刻`，直打点无相减。打点语义 = 种子主机卡片（20 张 `.host-card`）全部渲染。信标行 URL 编码（`%7C`）。
- **P1 历史口径（降级保留，勿再引用为门数据）**：v1 = s2-key-mode 信标 − 400ms（漏计 sleep(300)）；v2 = −700ms 修正。均只证明表单阶段时序。原始 runs 保留 `operable_ms_v1_400offset` 字段与污染原值注记（cold.json idx3/4 含 `polluted_original_operable_ms_v1`：2140/1856ms）。
- **P95**：`statistics.quantiles(n=20, method="inclusive")[18]`（exclusive 在小样本外推，弃用）。
- **样本数**：P1 冷/热各 10；P3 30；P6 100。
- **异常值**：不剔除；污染样本重跑替换并保留 `replaced` 注记。
- **仪表下限**：P1/P3 stderr/beacon 轮询 5ms；P2/P4/P7 像素端点 = screencapture 周期（40-90ms），全部报告为**上限值**；P2 v1 的 ev.py 仪表开销（spawn + 2×50ms sleep ≥100ms）使旧数据无法检验 100ms 门——已弃用。

### 3.3 P6 资源循环（raw/p6_cycles.json）——降级为「进程启动/退出残留试验」

- 联审 Q-02：每轮整进程 spawn→TERM **不能证明同一进程内反复会话开关不泄漏**（进程退出清空应被观测的进程内积累）→ 原"无线性增长"达标结论**撤回**。
- 保留证据（有效范围仅限进程级）：100 循环应用级残留 0/100（每循环差分归属 + 退出消失核验）；首10 254.00 → 末10 252.94 MB（Δ −1.06）；单循环 spawn→就绪中位 310ms。
- **同进程门定义（冻结，待受控窗口执行）**：同一 release 进程内 100 次会话创建/关闭（UI 驱动）+ 200 次标签切换（⌘1/⌘2，旧版已具备，App.tsx:1230-1246）+ 50 次侧栏分区变化（审批/文件/转发）；每存活会话输出订阅计数 ≤1 的旧版观测手段缺失——该子项如实标**旧版未完成**（`debug_subscriptions` 为 C10 新契约），新版在对应 R 任务直接断言。
- 事实更正：v1 文档称"旧版无标签概念（三列固定布局）"**错误**——旧版有标签切换（⌘1-9 捕获层、⌘W 关闭、⌘⇧[ ] 循环）。

### 3.4 P5 内存试点（raw/p5_pilot.json）——历史数据不可判，仪表有效性重新打开

历史 v3 记录 B=345.83 MB、E=117.05 MB，表观下降约 66%；记录声称 3 个候选身份保持、零残留。以上是原始记录的内容，不是本次认可其归属和总量计算有效。

- WebContent/GPU/Networking 的 RSS 同步下降提示可能存在系统压力或页回收，但没有同期 `vm_stat`/系统压力证据，**不能确诊“外压 purge”，也不能据此排除应用资源问题**。
- 本次对当前 `memsample.py` 的[纯数据探针](../2026-10-06-e2ebdc4-signoff/memsample-probe.json)复现：S0 旧 PID 误入候选、有效候选误判消失、退出同 PID 换身份误 PASS，以及键类型在探针中归一后仍将 1 MiB 应用 + 1 MiB helper 计为 3 MiB。须核对历史脚本与数据的版本绑定，当前代码不能证明历史数据有效。
- **撤回“v3 归属机制实证有效”和“P5 采样器通过”**。v1/v3 数据保留为历史参考，均不得作为门通过证据；不将表观下降计为内存达标。
