## 其他发现（第一次使用的真实感受）

1. **表单下拉框太窄，当前值完全读不出**（上面 #2 已述）。三个字段（用户名/认证方式/远端编码）挤在一行，两个下拉各只有 55px。「远端编码」这词本身对我有点陌生，但选项里的「中文 Windows / 老旧设备」提示让我能猜。真正的问题是关了菜单就只剩「UT」两个字母。
2. **用户名输入框没有任何提示**。名称和地址都有「例：……」，用户名是空白的，我第一次填的时候不确定该填登录账号还是随便起个名（pv_novice_01_addform.png）。
3. **hover 主机卡时，地址那一行会被按钮遮住一部分**：hover prod-1 时地址显示成 `ops@10.0.0...1:22`，中间被截断；移开鼠标又恢复完整。主机名没被挡，但地址被挡了——我恰恰可能在 hover 时想核对 IP（pv_novice_10_hover_clean.png vs pv_novice_09_unhover_clean.png）。
4. **「首次连接确认」弹窗让我核对指纹**，还说「可向管理员确认」——这句提示救场了，不然我真不知道 `SHA256:DemoFingerprint-xxx` 该去哪对（pv_novice_03_saved.png）。
5. 会话列表里 `stagin... · 已断开` 名字被截断，扫一眼分不清是哪台（轻微）。

## 给开发的问题清单

1. 添加主机表单里的两个下拉（认证方式/远端编码）能否加宽，或独占一行？现在收起状态只显示「密」「UT」，等于没有显示。
2. 用户名输入框能否也给个 placeholder（如「例：ops 或 root」）？名称和地址都有例子，唯独它没有。
3. hover 浮现的操作按钮能否只遮空白、不遮地址文字？比如 hover 时地址缩短让位，或按钮竖向只对齐第一行。
4. 会话卡名称截断（`stagin...`）能否给 title 悬浮提示全名？（主机卡有 title 显示 `ops@10.0.0.11:22 + 指纹`，会话卡不确定有没有）
5. 「远端编码」对我这种新手是个生词，是否考虑在 label 旁加一句灰字说明，比如「老设备中文乱码时选 GBK」？现在要靠展开选项才能看到解释。
