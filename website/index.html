01 /

连接，开箱即用

CONNECT & RESUME
01.01 HOSTS

本机与远程，平起平坐

置顶的「本机」条目开机自动打开。本地会话享有和远程一样的标签、分屏、命令块、搜索与文件浏览——不必在两个应用之间来回切。

01.02 AUTH

TOFU、2FA，一次走完

首次连接核验主机指纹并记住信任；口令、密钥与二次认证按序衔接。tmux 多面板复用同一条连接——一次登录，一次 2FA。

01.03 CONFIG

读懂你的 ~/.ssh/config

既有主机别名、端口与密钥配置直接解析复用，不用把多年攒下的连接信息重新抄一遍。

01.04 RESUME

关掉，再开，现场还在

正常退出时写入加密快照，下次启动经完整 TOFU / 2FA 流程回放会话。tmux 工作区崩溃安全，一键恢复排布。

01.05 VAULT

凭据进加密保险库

密码、私钥、会话快照与执行记录全部加密落盘，主密钥交给系统钥匙串。本地优先，凭据不出机。

01.06 PORTABLE

单文件，带着走

Windows 单个便携 exe，只依赖系统自带 WebView2，无需 VC++ 运行库；macOS / Windows 支持一键签名自动更新。

03 /

一条连接，六扇窗

TMUX, FIRST-CLASS
03.1

面板复用同一条连接

一条 SSH 上最多 6 个并排面板，共享一次登录与一次 2FA；拖拽排布，全屏会话墙一眼看遍。

03.2

工作区记忆，崩溃安全

面板布局随工作区落盘，异常退出后也能一键恢复上次的排布与现场。

03.3

广播输入，打一次发多机

iTerm 风格广播：同一条命令同时进多个会话。粘贴与重跑永不广播——批量操作也有分寸。

03.4

Android 上也能用

触屏助力球补方向键、Home / End、PgUp / PgDn 与 ^B 前缀，横屏、平板与外接键盘优先，有会话时前台保活。
