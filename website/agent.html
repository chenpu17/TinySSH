01 /

人机同一条审批链

ONE GATE FOR EVERYONE
01.1

同一张危险形态表

Agent 执行命令，走的是和人类粘贴 rm -rf / 完全相同的规则引擎——没有特权通道，没有例外名单。

01.2

传输必审，逐条确认

上传下载永远逐条审批。自主模式可按会话开启，跳过逐条命令审批，但危险形态与传输仍然硬拦截；仅内存态，重启即失效。

01.3

显式的控制权交接

Agent 只在你委派后才驱动会话，随时一键接管。拒绝也会被记录——审计不撒谎，键序直写不记成命令块。

03 /

一切皆有记录

NOTHING GOES UNRECORDED

加密的执行记录，保留 30 天。每一次执行、每一次拒绝、每一次审批，落在双层泳道时间线上——你的操作与 Agent 的操作分列，永远不混淆。

你和 Agent 都可查询。记录不是黑盒：Agent 能回溯自己做过什么，你能审计它为什么做。终端回放与记录归因不撒谎——键序直写 PTY 不记成命令块。
